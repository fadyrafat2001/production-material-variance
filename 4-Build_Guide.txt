# Data dictionary
Synthetic inputs only. CSVs use UTF-8, comma delimiters, dot decimals and a header row.

## production_orders.csv
One row per Order_ID (36 unique keys). Month is YYYY-MM. Product is one of Panel A/B/C. Planned_Output_units is the original planned finished output; Actual_Output_units is achieved finished output. Quantities are units, not kg.

## material_consumption.csv
One row per Order_ID + Material (72 unique pairs). Each order has Resin and Filler.
Actual_Output_units repeats by material solely to compute the allowed material quantity; it is not additive across materials.
Standard_kg_per_unit is the standard input mass per finished unit.
Standard_Price_EGP_per_kg is the standard material price.
Actual_Consumed_kg is material issued and consumed.
Actual_Issue_Price_EGP_per_kg is the per-kg cost of that consumption, not a purchase transaction.

## Dimensions
DimProduct: 3 unique Product values; DimMaterial: 2 unique Material values; DimMonth: 3 unique Month values. All fact keys must be found in these dimensions.
DimMonth is a period dimension, not a daily date table. No built-in time-intelligence calculations are claimed.

// Draft M. Not executed in Power Query. Create text parameter DataFolder first.
let
    Source = Csv.Document(File.Contents(DataFolder & "material_consumption.csv"), [Delimiter=",", Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    Headers = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    Typed = Table.TransformColumnTypes(Headers, {{"Order_ID", type text}, {"Month", type text}, {"Product", type text}, {"Material", type text}, {"Actual_Output_units", Int64.Type}, {"Standard_kg_per_unit", type number}, {"Standard_Price_EGP_per_kg", type number}, {"Actual_Consumed_kg", type number}, {"Actual_Issue_Price_EGP_per_kg", type number}}, "en-US"),
    Allowed = Table.AddColumn(Typed, "Standard_Allowed_kg", each [Actual_Output_units] * [Standard_kg_per_unit], type number)
in
    Allowed

DAX MEASURE DEFINITIONS (exact source, add separately)

// Draft definitions. Add each measure separately in Desktop. Not executed in DAX.
Standard Cost EGP = SUMX(FactMaterial, FactMaterial[Standard_Allowed_kg] * FactMaterial[Standard_Price_EGP_per_kg])

Actual Cost EGP = SUMX(FactMaterial, FactMaterial[Actual_Consumed_kg] * FactMaterial[Actual_Issue_Price_EGP_per_kg])

Price Variance EGP = SUMX(FactMaterial, FactMaterial[Actual_Consumed_kg] * (FactMaterial[Actual_Issue_Price_EGP_per_kg] - FactMaterial[Standard_Price_EGP_per_kg]))

Usage Variance EGP = SUMX(FactMaterial, (FactMaterial[Actual_Consumed_kg] - FactMaterial[Standard_Allowed_kg]) * FactMaterial[Standard_Price_EGP_per_kg])

Total Variance EGP = [Actual Cost EGP] - [Standard Cost EGP]

Variance Pct = DIVIDE([Total Variance EGP], [Standard Cost EGP])

Reconciliation EGP = [Total Variance EGP] - [Price Variance EGP] - [Usage Variance EGP]

Order Count = DISTINCTCOUNT(FactMaterial[Order_ID])

Actual Output Units = SUM(Orders[Actual_Output_units])

Planned Output Units = SUM(Orders[Planned_Output_units])

// Guard against a misleading material-level output denominator.
Actual Output Units Safe = IF(ISCROSSFILTERED(DimMaterial[Material]), BLANK(), [Actual Output Units])

# Production material cost variance

**Review draft. Synthetic data. Assistant-prepared starter case study, not prior independent work or real business results.**

## Business question
How much of the direct-material cost overrun comes from issue prices, and how much from consumption above the quantity allowed for actual output?

## What exists
- Working Excel workbook with formulas, product/month summaries and chart.
- 36 synthetic orders and 72 order/material lines across July to September 2026.
- CSV inputs, a data dictionary, and independently calculated acceptance totals.
- Power BI preparation assets: M import/transformation query, DAX measures, dimension CSVs, relationship and report build instructions.

## What does not exist yet
No PBIX, implemented Power BI model, rendered Power BI report or executed M/DAX is included. The Power BI assets require Desktop build and testing. The Excel workbook is not a Power BI report. No PivotTable or Excel Data Model is implemented in the workbook.

## Open the Excel example
Open `Production_Material_Variance.xlsx`, start at Summary, then read Guide. Blue numerical cells on Material detail are inputs. Formula ranges cover the original 72 rows; extend the ranges and charts if adding rows. The underlying dataset is in `data/`.

## Method
Standard allowed kg = actual output × standard kg per finished unit.
Standard cost = standard allowed kg × standard price.
Actual cost = actual consumed kg × actual issue price.
Price variance = actual consumed kg × (actual issue price - standard price).
Usage variance = (actual consumed kg - standard allowed kg) × standard price.
Total variance = actual cost - standard cost = price variance + usage variance.

Positive means adverse; negative means favourable. All prices are illustrative EGP/kg. The price variance is measured on consumption, not purchase quantities. Planned output is context only, not the cost comparison baseline.

## Findings in the designed scenario
Standard allowed cost: EGP 7,349,004.00. Actual material cost: EGP 7,787,953.52.
Adverse total: EGP 438,949.52 (5.97%). Price: EGP 256,311.44. Usage: EGP 182,638.08.
September contributes EGP 327,687.88 of the variance. Panel C contributes EGP 226,238.76 across the full period. These are designed sample patterns, not evidence of a real cost saving or a cause such as supplier failure.

## Acceptance and scope
All 72 detail lines and total reconcile to zero within EGP 0.01. See `docs/EXPECTED_RESULTS.json`.
Only consumed direct materials are covered. Labour, overhead, inventory valuation, profit and mix/yield splits are excluded.
The output units repeat across materials; do not sum output from the material fact. Use the Orders table for output measures.
